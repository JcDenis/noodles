Settings
Check the box to show avatars on this blog. "Image API" gives the images. "Default image" is the avatar of an e-mail address without image: "API" for the service default, "Local" for your own image (a file default-avatar.png at the root of the media manager or in the img folder of the theme).
Behaviors
Check each place where to show avatars, and set the size, the rating, the CSS of the image. Entries and Comments avatars are added on the entry page. For the other lines, an avatar is added by a script near each element found with the CSS selector of "Target", at the "Place" you choose.
