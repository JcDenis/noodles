Réglages
Cochez la case pour afficher des avatars sur ce blog. « API des avatars » fournit les images. « Avatar par défaut » est l'avatar d'une adresse e-mail sans image : « API » pour l'image du service, « Locale » pour votre propre image (un fichier default-avatar.png à la racine de la médiathèque ou dans le dossier img du thème).
Behaviors
Cochez chaque endroit où afficher des avatars, puis réglez la taille, l'évaluation et le style de l'image. Les avatars « Entrées » et « Commentaires » sont ajoutés sur la page d'un billet. Pour les autres lignes, un script ajoute l'avatar près de chaque élément trouvé avec le sélecteur CSS de « Cible », à l'« Emplacement » choisi.
